# Simple TCP Port Scanner

Program Python sederhana untuk memindai (*scanning*) status port TCP (terbuka atau tertutup) pada suatu alamat IP dalam rentang (*range*) port yang ditentukan.

## 🚀 Fitur
- Meminta input Alamat IP target secara interaktif.
- Meminta input rentang port (port awal hingga port akhir).
- Menampilkan status terbuka/tertutup untuk setiap port secara *real-time*.
- Menyimpan dan menampilkan daftar semua port yang terbuka di akhir pemindaian.

## 🛠️ Prasyarat & Teknologi
- Python 3.x
- Modul `socket` (bawaan dari Python, tidak perlu instalasi tambahan)

1. Jalankan script melalui terminal/command prompt:
